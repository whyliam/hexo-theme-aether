# Example content

After installing the theme in a new Hexo site, copy `_config.aether.yml` beside the site's `_config.yml` and copy the contents of `source/` into the site's `source/`. Keep existing files when adapting a populated blog.

Set `theme: aether` and `language: en` in the site configuration, then run `npx hexo clean && npx hexo generate`. The sample profile and essays are demonstration content; the runtime package does not require them.
