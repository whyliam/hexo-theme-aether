# 第二轮精修：主体行为与系列层级

2026-11-08。依据用户提供的 [新一轮设计思考](https://chatgpt.com/s/t_6af01f4cfbcc8191a4d8d14bffa59d9a)，只推进三个优先级，不更换视觉风格、不增加页面模块。时间索引在参考中属于可选后续增强，本轮不加入。

## 实施

### P0：Hero 的空间与行为

保留现有哑光玉石书页。相机距离由 7.2 改为 6.15，主体视觉尺寸约增加 17%；模型向右上微调。Hero 容器及其高度约束不增加，文字区不叠加装饰。

五层曲面按 180ms 的层间偏移逐层舒展，每层 1.6s、总长约 2.32s，使用平滑曲线停留在最终姿态。每次页面运行只展开一次，媒体偏好切换不会反复播放。原先的整体周期摆动移除；鼠标只改变相机位置，模型本身不跟着旋转。

展开结束且观察视角不变时不再重复绘制 3D 主体。mesh 沿用原有单层低对比背景，没有新增背景动画。移动端收回环境光边界，避免装饰溢出。静态图重新由同一模型最终姿态导出；移动端、减少动态效果和低性能回退继续有效。

### P1：一个重点系列

新增站点配置 `aether.series.featured`（系列名称或 slug）与 `featured_description`。Liam 的配置指定 `Newsletter 周刊`，内容与数字仍来自真实文章聚合。

Newsletter 展示真实起止年份、145 篇文章、简介、最新与上一篇文章、最近更新。其他系列按篇数从高到低采用轻量双列条目：名称、累计篇数、起始年份、最新文章与更新时间。窄屏堆叠为单列。未配置或找不到重点系列时不虚构推荐，不依赖“数组第一项就是重点”。

这次仅改变无项目的首页系列分支，原有项目/系列组合配置仍受支持。

### P2：辅助文字规格

首页统一 `--aether-type-meta: 12px`、`--aether-type-support: 14px`，辅助灰度复用 `--aether-muted`。日期和标签行高 1.6，摘要/说明行高 1.75；统一日期到标题、标题到摘要的间距。沿用既有暖白、苔绿与中文衬线栈。
