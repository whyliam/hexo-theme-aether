# Aether 设计规范

更新日期：2026-11-08。适用范围：Aether scheme；其他 NexT scheme 不在本文范围内。

本轮首页升级详见 [Ambient Home](design/ambient-home.md)：Hero 已改为左右分栏的玉石书页与动态 mesh；下文旧版介绍区高度与布局数值保留为前一阶段记录，以该升级文档为准。

本文以仓库当前实现为依据，区分已经实现的设计与后续统一事项。博客站点的文案、精选文章和频道属于站点配置，不应固化为主题品牌。

## 1. 设计定位

**有机风格为主，辅以编辑式排版。** 服务于持续写作的个人博客，让读者先找到文章，再了解作者与长期主题。

有机感来自低饱和苔绿、柔和色彩过渡、非对称圆角和自然留白；编辑感来自标题、日期、摘要的层级，以及清晰的内容分组。正文与导航应立即可读。

设计决策顺序：阅读可达性 → 内容层级 → 中文可读性 → 视觉表达 → 交互细节。装饰不能推迟文章进入首屏，也不能依靠动画隐藏核心内容。

## 2. 首页信息架构

```text
导航：品牌 / 首页 / 写作 / 系列 / 影像 / 关于 / 搜索 / 主题切换
  ↓
简短介绍：名字 + 一句话写作方向 + 关于我
  ↓
最新文章：6 篇，第一篇适度突出 + 所有文章入口
  ↓
精选阅读：按阅读意图组织的指定代表作
  ↓
长期系列：主题 + 最新文章 + 篇数 + 最近更新 + 系列入口
  ↓
短札与影像：补充阅读与视觉记录
  ↓
订阅渠道与关于 → 页脚
```

| 模块 | 阅读任务 | 约束 |
| --- | --- | --- |
| 简短介绍 | 确认是谁、写什么 | 目标高度 150–220px；当前最小高度 180px，长文案可自然增高 |
| 最新文章 | 快速发现新内容 | 建议 5–8 篇，默认 6 篇；按发布日期排列；第一篇使用浅色底，不额外放大成整屏 |
| 精选阅读 | 找到值得开始的代表作 | 优先显式配置文章；不使用最近文章列表代替编辑选择 |
| 长期系列 | 进入持续追踪的主题 | 展示名称、篇数、最近更新；最新文章提供阅读线索 |
| 短札与影像 | 探索补充内容 | 视觉权重低于最新文章；影像应有清晰封面 |
| 订阅与关于 | 找到持续关注与联系入口 | 简短渠道列表；如邮件订阅未开放，目标页应明确说明 |

入口由 `layout/index.njk` 决定；旧 Building 模板仍在仓库，但已不在首页渲染顺序中。避免同时展示“当前关注”和相同内容的“正在构建”。

## 3. 颜色与作用域

基础变量在 `source/css/_schemes/Aether/index.styl`；首页覆盖在 `_reading-home.styl`。目前苔绿只作用于 `.aether-home`，全站其他页面和导航仍可能继承基础墨蓝。不要把首页配色误认为已经完成全站迁移。

| 语义 | 基础浅色 | 首页浅色 | 首页深色 |
| --- | --- | --- | --- |
| 页面背景 `--aether-paper` | `#faf8f3` | 继承 | `#141416` |
| 表面 `--aether-surface` | `#ffffff` | 继承 | `#1c1c20` |
| 主要文字 `--aether-ink` | `#181818` | 继承 | `#ece8e0` |
| 次级文字 `--aether-ink-2` | `#2a2a2a` | 继承 | `#cac6bc` |
| 摘要/日期 `--aether-muted` | `#6b6660` | 继承 | `#aaa99e` |
| 强调色 `--aether-accent` | `#2a3a6b` | `#345b4b` | `#a9c9ad` |
| 强调底色 `--aether-accent-tint` | `#eef0f7` | `#e8eee7` | `#24352d` |
| 分隔线 `--aether-rule` | `#e7e1d3` | `#dce2d9` | `#39463c` |

渐变仅用于介绍区：浅色以 `#e3eadb`、`#ede8da` 为柔和色点，使用 OKLab 插值，并保留普通 CSS 渐变作为回退；深色以 `#304235` 与 `#222b25` 形成静态背景。长文和文章摘要不叠加复杂背景。

强调色用于链接反馈、焦点、最新文章标识与局部表面；不要用彩色大字反复强调标语。深色模式逐项验证标题、摘要、日期、链接和背景，不能只反转页面底色。

## 4. 字体与排版

主题使用字体栈，不保证所有访问者都安装了首选字体。中文需验证系统回退后的实际效果。

| 角色 | 字体栈核心 | 首页桌面字号 | 手机字号 |
| --- | --- | --- | --- |
| 作者名字 | Source Serif Pro / Iowan Old Style / Charter / Songti SC | 34px | 28px |
| 模块标题 | `--aether-ff-serif` | 27px | 24px |
| 最新一篇标题 | `--aether-ff-serif` | 27px | 21px |
| 普通文章标题 | `--aether-ff-serif` | 21px，行高 1.5 | 21px |
| 一句话介绍 | Geist / 系统无衬线 / PingFang SC | 15px，行高 1.7 | 14px |
| 摘要 | `--aether-ff-sans` | 14px | 14px |
| 日期 | JetBrains Mono / 系统等宽 | 12px | 12px |

标题左对齐，长标题自然换行；列表摘要可以截断，文章正文不能因排版截断。标签和辅助分类不应抢占标题宽度。等宽字体主要用于日期与少量数据，不用于大段中文说明。

## 5. 布局、间距与圆角

| 项目 | 当前值 |
| --- | --- |
| 首页模块容器 | 最大宽度 1180px，包含水平内边距 |
| 模块水平内边距 | `clamp(20px, 4vw, 56px)` |
| 介绍区 | 最大宽度 1068px；宽度 `calc(100% - 40px)` |
| 介绍区内边距 | 桌面 32px 40px；手机 24px |
| 介绍到最新文章 | 最新模块 `margin-top: 36px` |
| 后续模块间距 | 桌面 56px；手机 40px |
| 列表行内边距 | 普通 22px 12px；最新一篇 26px 24px；手机 20px 12px |
| 介绍圆角 | `24px 48px 24px 24px` |
| 最新文章圆角 | `18px 32px 18px 18px` |
| 首页通用中圆角 | 16px |

区别对待内容容器：普通文章使用分隔线列表，精选与系列使用有边界的卡片，介绍区使用柔和背景。卡片默认无投影，避免所有内容变成相同的圆角方块。

## 6. 组件约定

| 组件 | 内容与行为 | 实现入口 |
| --- | --- | --- |
| 简短介绍 | `hero.name`、`hero.intro`；缺省回退作者/站点信息；关于链接 | `layout/_partials/home/hero.njk` |
| 文章行 | 日期、分类、标题、摘要；整行链接；第一篇 `is-latest`；首页隐藏标签 | `latest.njk` |
| 精选路径 | 阅读意图、说明、指定文章；隐藏装饰编号后同步调整链接网格 | `start-here.njk` |
| 系列卡片 | 名称、最新文章、数量、最近更新；进入系列页 | `series.njk` |
| 短札与影像 | 桌面并列、窄屏堆叠；分别保留全部入口 | `notes-visuals.njk` |
| 订阅栏 | 从配置读取渠道，补充关于入口 | `newsletter.njk` |
| 搜索面板 | 全站内容检索、键盘导航、关闭后返回页面 | `source/js/aether-cmdk.js`、`_cmdk.styl` |

列表和卡片不得嵌套交互链接。新组件使用 `aether-` 前缀；优先复用语义变量，避免在单个组件内建立另一套配色。

## 7. 响应式

首页新规则以 767px 为手机断点：介绍上下排列；文章日期与分类同一行，标题与摘要占满下一行；精选、系列变为单列；隐藏纯装饰箭头。

桌面精选为三列、系列为两列，均使用 `minmax(0, 1fr)` 约束内容。网格子项设 `min-width: 0`，防止长中文或英文标题撑宽页面。旧模块仍有各自断点，修改时需一起检查。

验收至少覆盖 320、390、768、1323px；同时检查长标题、无摘要、无封面、长系列名。介绍区高度目标依赖短文案，不能用固定高度裁掉内容。

## 8. 交互、动效与无障碍

- 内容默认可见；博客配置目前设 `motion.enable: false`，不等待入场动画显示导航或正文。
- 首页阅读模块已移除滚动 reveal 标记；旧 reveal 实现仍在代码中，新增模块不应重新依赖它。
- 普通交互优先颜色或边框反馈，常见时长 120–180ms；文章标题颜色过渡为 160ms。
- 文章、精选和系列卡片悬停不位移、不抬升；其他历史组件的动效需单独核查。
- 键盘焦点使用 2px 强调色轮廓、5px 偏移；焦点不能被容器裁剪。
- 支持 `prefers-reduced-motion`，不依赖移动、颜色或背景装饰传递唯一信息。
- 核查正常、悬停、焦点、按下、深浅色状态。图片有合适替代文本；核心入口应易于触控。

## 9. 页面职责

| 页面 | 应优先呈现 | 设计约束 |
| --- | --- | --- |
| 首页 | 最新文章与精选入口 | 短介绍，文章进入首屏 |
| 归档/写作 | 日期与标题 | 易扫读，年份导航清楚 |
| 系列索引 | 长期主题 | 数量与更新信息清楚 |
| 系列详情 | 主题介绍与文章路径 | 区分倒序更新与推荐阅读顺序 |
| 文章 | 标题、摘要、正文、目录 | 控制阅读宽度；目录辅助阅读，不挤压正文 |
| 影像 | 清晰封面与地点/时间 | 避免空色块主导画廊 |
| 关于 | 作者信息、代表工作、联系 | 精简重复宣言 |
| 订阅 | 可用渠道和当前状态 | 不承诺尚未开放的邮件入口 |
| 分类/标签 | 可浏览的内容索引 | 中文标题；大量标签应有筛选或分组 |

此表为持续维护约束，不代表所有内页已经完成改造。

## 10. 配置与代码边界

主题负责结构、变量和组件；站点 `_config.aether.yml` 负责名字、介绍、精选文章、渠道与模块开关。不要把 Liam 的文章或身份写死在模板中。

当前首页配置重点：`aether.hero.name`、`aether.hero.intro`、`aether.latest.limit`、`aether.start_here.items[].posts`、`aether.series.enable`、`aether.newsletter.channels`。精选仍兼容分类、标签等回退，但站点编辑应优先指定代表作。

样式加载关系：`Aether/index.styl` 引入基础布局与 `_home.styl`，最后引入 `_reading-home.styl` 覆盖新首页。维护新首页时优先修改后者；更改共享变量要检查所有内页。

## 11. 已知差异与后续整理

| 当前情况 | 后续目标 | 原因 |
| --- | --- | --- |
| 首页苔绿，内页与导航仍保留墨蓝变量 | 明确是否全站统一，再迁移共享变量 | 避免把局部覆盖当成全站设计系统 |
| `_home.styl` 保留旧 Hero、卡片和 reveal 样式 | 核查所有引用后合并或移除失效规则 | 降低覆盖层级与维护成本 |
| 首页隐藏编号，但模板还生成编号节点 | 如无兼容需求，再清理节点 | 避免只删节点导致网格错位 |
| 通用配置仍含部分旧 Hero 字段和模块标签 | 更新配置说明，标注兼容字段 | 避免使用者配置无效展示项 |
| 其他内页仍存在旧信息架构和视觉细节 | 按页面职责逐页验收 | 本轮首页完成不等于全站完成 |

旧版探索见 [趋势分析存档](design/archive/2027-trends.md)，其中评分、趋势预测与动效建议不作为当前验收依据。

## 12. 修改后的验收

1. 首页顺序符合第 2 节；最新文章为 5–8 篇，第一篇适度突出。
2. 介绍保持简短，首屏能看到具体文章标题；精选不重复最近文章列表。
3. 系列的数量、最近更新与链接来自真实数据；空模块不输出空白区域。
4. 320、390、768、1323px 均无横向溢出；长标题不挤窄到逐字竖排。
5. 深浅色模式下标题、摘要、日期、链接与焦点均可辨认。
6. 内容无需等待动画出现；键盘能进入链接和搜索，关闭搜索后可继续操作。
7. Hexo 生成成功，内部链接可访问；检查生成文件，浏览器验证时排除旧 CSS 缓存。
8. 运行与变更相关的测试和检查；明确记录已有失败，不能用局部通过代替全站验证。
